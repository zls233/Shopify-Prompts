# 功能削减

本文件是 Shopify-Prompts 项目内功能削减范围的唯一权威清单。其他页面构建任务应引用本文件，不重复维护完整清单。

在当前 Shopify Theme、Menus、Pages、Header、Footer、移动导航及页面 CTA 中，不添加或复刻以下功能的入口、组件、交互或无效占位：账号管理、登录、注册、在线聊天/客服聊天组件、礼品卡、捆绑购买、Email Newsletter/邮件订阅/Email Signup。对已存在项按本任务范围移除其入口及专属组件；不得只用 CSS 隐藏后留下可点击入口。

不要删除普通静态帮助页面，例如 Shipping、Returns、Warranty、FAQ、Contact 或 Stores；这些内容不因属于 Customer Service 分类而自动排除，保留的链接必须通向真实页面。不得删除无关 Shopify 商品或店铺资源。

先列出实际发现的入口和文件，再做最小范围修改。不要删除无关 Shopify 商品或店铺资源，也不要只用 CSS 隐藏后留下可点击的空链接。检查桌面和移动端的导航、Footer、商品页和弹窗，保存修改清单和截图。
