# 6-1｜全站验收、精细视觉复核、差异修复与交付（FAST 完整阶段）

> 先读 `STAGE_COMPLETION_CONTRACT.md` v3、`VISUAL_FIDELITY_STANDARD.md` 和当前项目记录。默认 FAST **不等于只做购物流程/大面积错位**：2-1/4-1 的范围内视频、动效、素材、像素级差异属于交付硬门槛，不能继续标为 P2。对 Store、Theme、参考版本均一致的有效截图和交互证据可复用，缺失/失效才补测；不必每阶段重复采集全站。

## 默认执行

**独立检查导航双门禁**：执行 `NAVIGATION_LINK_GATE.md`，对照源站和实际 Draft 的 Desktop/Mobile Header/Mega Menu、展开交互、首页 CTA，以及全部范围内 Menu/Section/JS/JSON/Liquid 链接最终 hostname、真实资源类型与内容。检查重跑同步脚本是否恢复原官网 fallback。6-5 的 404 检查不能代替外跳审计；0 个外链不能代替 Header 高保真对照。


1. **核验上下文与版本**：读取当前 Store、授权身份、Draft/Live、Git、2-1/4-1 的 coverage/视觉差异矩阵、素材和动效清单及可信远端 readback；特别筛出历史 `completed_core` 但视觉 P2 未做的遗留项，列入本轮必修清单。
2. **商品与分类**：全量 API 读回目标店铺商品 ACTIVE、可跟踪 Variant 在已确认 Location available=9999、实际价格/Variant/SKU、分类成员、导航目标；可复用未变化且有效的批量证据。运行 `6-6` 的全覆盖分类数据对账 + 分层代表性浏览器检查。
3. **视觉与媒体完整性**：按已确认范围逐模板/Section核查 Home 首屏至页尾、Header/Mega Menu、PLP、PDP、Cart；图片/字体/crop/响应式和实际视频源、poster、加载解码/播放；hover/active、轮播、动画时长/easing、sticky、scroll 等交互状态。源站/目标同 viewport 截图与尺寸测量证据必须齐全（至少 1440×900 / 390×844，实测断点补宽度）。已有 4-1 真实高保真矩阵未变可复用，**只有 Theme Check、功能 smoke 或几张截图不算视觉通过**。
4. **修复差异**：可复现且可修复的范围内素材、视频、动效、文字换行、字体、Section/图片位置及像素差异，调用 4-2/4-3/4-4 对问题根因做修改 → 准确 Draft push → readback → 远端视觉回归。没有因差异“不影响购买”而自动延期的例外；有进展继续修，外部同根因无进展时按 v3 有限恢复后记 blocked。
5. **购物与体验**：在 Desktop/Mobile 真实 Draft 上执行菜单、过滤/排序、变体选择、图集、Add to Cart、数量更新/移除、Cart 与批准的 Checkout 入口。不得模拟支付、完成订单或复刻源站 Checkout。
6. **固定内容**：Footer 两栏八链接真实指向用途正确的页面，无社媒/Newsletter；公告栏仅显示 `05-customization/5-2-功能削减.md` 规定的文本。模板文本的法律/运营审查独立标注。运行 `6-5` 链接/Not Found 差集扫描、修复并复测。
7. **授权边界**：Live 发布、解除密码、第三方支付及公开后的 Checkout 入口真实测试分别依此前明确授权执行；未授权 `not_run`，不阻止合格的 Draft 部分，但不能称整个 Live/支付已验收。
8. **记录单份结果**：Store/Theme ID、数据覆盖与差集、区块与 viewport 视觉覆盖、视频/动效通过数、远端证据、剩余异常/阻断、恢复入口；不重复保存长日志。

## 验收与状态

- 当前范围内数据/导航/真实购物、**全部可执行视觉 Section、媒体/视频、精细动画、响应式和像素级对照**均核验通过、无已知可修复差异，Draft 范围才能报告 `completed_full`。
- 若历史 2-1/4-1 有视频、动画、素材、全页像素级精修未完成，须继续修复或标记 `partial`；**禁止把“Draft 核心功能已通过”写成 6-1 的全量交付完成**。
- 真实不可解决的权限/源站/媒体阻断按 `blocked_core` 或独立 `blocked` 记证据与影响；明确排除页面和未授权发布独立 `excluded/not_run`，不回头恢复已删范围。
- 额外的全商品逐页视觉测试、多浏览器全矩阵等在用户未指定时仍可风险抽样，但这**不削减默认已列入范围的全 Section 和视频/动画/像素精修工作**。

阶段报告保持简洁；完整规范在 `VISUAL_FIDELITY_STANDARD.md`。
