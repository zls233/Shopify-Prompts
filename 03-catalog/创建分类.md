开始本任务前，先执行或复核 `00-project/建站授权准备.md`。确认目标店铺、执行 App 身份，以及商品、Collections、Menus、发布和 Metaobjects 所需的实际授权；缺失时先完成授权，再写入资源。已有有效授权时直接复用，不重复创建应用。

分析当前 Shopify 主题和参考页面的完整导航与商品分类结构，然后根据页面实际结构配置 Shopify 的 Products、Collections、Menus、Metaobjects 和主题导航。

目标是实现：

用户在网页导航中点击某个品类，例如：

Women → Clothing → Pants

能够进入对应 Collection 页面，并且只显示属于该分类的商品。

具体要求：

首先分析参考页面现有的 Header、Mega Menu、Footer、Collection 页面和商品页面，提取完整 taxonomy / category hierarchy。
不要只修改前端写死导航。优先使用 Shopify 原生数据结构实现：
Products：商品本身
Tags / Product Type / Metafields：商品分类属性
Automated Collections：商品集合
Menus：导航结构
Metaobjects：Mega Menu、分类 Banner、图片、文案等结构化内容
扫描当前 Shopify 店铺中的所有商品，根据商品：
title
product type
tags
vendor
description
existing metafields
判断其所属分类。
建立统一、可维护的商品分类规则。
优先使用标准化 tags，例如：

gender:women
gender:men

category:clothing
category:shoes
category:accessories

subcategory:pants
subcategory:dresses
subcategory:sweaters
subcategory:sandals
subcategory:sneakers

根据实际商品和参考站 taxonomy 扩展。

为商品补充缺失的分类 tags / product type / metafields。
不要为了当前页面效果手动把商品 ID 写入主题。

根据分类结构创建 Shopify Automated Collections。
例如：

Women's Pants

conditions:
tag = gender:women
AND
tag = subcategory:pants

Women's Sandals

conditions:
tag = gender:women
AND
tag = subcategory:sandals

确保每个 Collection 的 handle 合理、稳定并具有可读性。

创建或更新 Shopify Navigation Menus，使导航层级与参考页面一致。
例如：

WOMEN
Clothing
Dresses
Pants
Sweaters
Shoes
Sandals
Sneakers

每个最终分类菜单项应该直接链接到对应 Shopify Collection，而不是使用前端 JS 自己过滤商品。

如果参考页面的 Mega Menu 包含：
图片
Banner
Featured Collection
标题
描述
CTA
Promo card
则建立合适的 Metaobject definitions 和 Metaobject entries 来保存这些结构化内容，并让主题从 Shopify Content 数据中读取。

先确定所有权：商家需要在后台长期维护的店铺自有 Metaobjects / Metafields，用同一 Admin GraphQL App 身份创建定义、再按稳定 handle 写条目和值、最后远端读回；项目 App 自有的 `$app` 定义先写入所属 App 的 `shopify.app.toml` 并部署，再用该 App 身份写条目。不要用 CLI Connector App 改写另一 App 的 `$app` 资源。商家自有 Metaobject 定义不要显式提交仅供 App 自有类型使用的 `access.admin` 设置；需要主题读取时配置 Storefront 读取权限。每次写入前先核对店铺、Client ID、实际 scopes、主题角色和 Online Store publication。

默认 dry run，并保留后台已存在的条目和值；重复执行只补缺失资源。定义类型或字段发生冲突时停止并输出差异，不能静默重建或覆盖商家编辑。将定义 GID、条目 GID、Page/Collection/Product metafield GID、handle、执行身份、错误与读回结果写入审计。主题只读取这些原生对象并为未配置值提供安全回退；先在未发布主题验证，再考虑上线。

不要把这些内容全部硬编码在 Liquid 中。

修改 Shopify Theme，使 Header / Mega Menu 直接读取 Shopify Menu。
优先使用：

section.settings.menu.links

以及：

link.links
