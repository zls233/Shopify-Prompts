# Cookie 提示

为站点实现首次访问时出现在页面下方的 Cookie 弹窗，提供“接受所有 Cookie”和“仅接受必要 Cookie”两个清晰按钮。优先参考已采集的 WebArchive、截图及原站移动端样式；没有可靠样式证据时沿用当前主题视觉系统。

两个按钮都应关闭弹窗，并分别在 `localStorage` 保存用户选择；刷新后不重复弹出。此阶段只实现可见 UI 和选择记忆，不实现追踪脚本拦截或完整 CMP。不要声称它提供了实际的非必要 Cookie 控制。

验证首次访问、两种按钮、刷新持久化、桌面和移动端布局、键盘可达性，以及弹窗不会遮挡加入购物车等核心操作。保存测试说明与两种视口截图。不要使用浏览器默认 `alert`。
